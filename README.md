# ML Project 
# 🎓 Student Exam Performance Predictor

A Machine Learning web application built using **Flask** and **Scikit-Learn** that predicts a student's Mathematics score based on demographic and academic information.

---

## 🚀 Live Demo

https://mlproj1.onrender.com

---

## 📌 Features

- Predict Student Math Score
- Machine Learning Pipeline
- Data Preprocessing
- Flask Web Application
- Beautiful Bootstrap UI
- Deployed on Render

---

- CSS3

- Gunicorn

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/srinjoy2006eb-glitch/mlproj1.git
```

Move inside the project

```bash
cd mlproj1
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```
